# Pack NOVA — quatre assistants Microsoft 365 Copilot

## Commencer
1. Lire le cahier Markdown principal : il contient l'intégralité du TP, les données, les instructions, les exercices et les tests.
2. Faire valider l'environnement et choisir le parcours A, B, C ou D avant la séance.
3. Préparer le dossier de connaissances avec les douze TXT du dossier corpus, selon le chapitre B de chaque métier.
4. Créer les quatre agents et copier les instructions depuis le cahier ou le dossier instructions.
5. Exécuter les tests et documenter les réponses dans la grille CSV ; ne pas attribuer de verdict avant exécution.
6. Appliquer une correction documentée puis rejouer les tests de non-régression.
7. Réaliser le fil rouge avec transmissions manuelles relues.

## Contenu
- Cahier complet Markdown : parcours pédagogique, tutoriels, exercices et corrigés dépliables, 24 tests métier et 4 fiches transverses.
- corpus : 12 fichiers TXT UTF-8, uniquement données fictives et non confidentielles.
- instructions : 4 blocs complets à copier dans Instructions.
- Grille CSV : 40 lignes initiales, soit 24 tests métier et 4 tests transverses déclinés sur 4 agents ; dupliquer pour les essais et répétitions.
- Repères formateur : organisation, points de vigilance, calculs attendus et validation.

## Précautions
Le CSV est une grille de suivi manuel à ouvrir dans Excel, pas un schéma d'import universel d'une fonction d'évaluation.
Le témoin de contrôle d'accès TR-03 doit être préparé séparément par le formateur : il n'est pas distribué aux comptes non autorisés.
Les sources Microsoft et institutionnelles sont citées dans le cahier avec les identifiants de la recherche ayant servi à sa préparation ; actualiser les pages officielles avant une nouvelle session si les interfaces ont évolué.
Les créations, tests, partages et publications dans le tenant restent à effectuer : aucun agent n'a été déployé pendant la fabrication de ce support.
La demande initiale s'interrompait en cours de phrase ; la fin du fil rouge a été explicitement complétée par une proposition pédagogique, sans supposer la suite manquante.
