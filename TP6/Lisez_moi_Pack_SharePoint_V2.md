# Pack V2 — SharePoint documentaire et Power Automate A/B

1. Lire le cahier participant V2 et effectuer S1–S8 ; le guide de correction reste réservé au formateur.
2. Charger la charte dans 01_Cadrage, le cahier dans 02_Exigences et le planning dans 03_Planning.
3. Le fichier Plan_Projet est un exemple documentaire, pas le classeur de mesure. Mesures_Tests sert à chronométrer et journaliser les tests.
4. Un vrai .mpp est créé localement avec Microsoft Project selon S6 ou fourni par le formateur ; aucun .mpp fictif renommé n’est inclus.
5. Les URLs sont créées après chargement sur VOTRE site ; les emplacements CSV ne doivent pas être utilisés comme liens réels.
6. Les flows lisent les valeurs de liste, affichent les liens et archivent le CR en HTML ; ils n’extraient pas les tâches .mpp ou le texte Word automatiquement.
7. Le ZIP est une archive de fichiers pédagogiques, pas une sauvegarde de site ni un export importable de flow. Le site doit être créé selon droits tenant.
8. Aucun envoi réel ni aucune création de site a été exécuté par le générateur de ce pack ; les tests locaux sont indispensables.
