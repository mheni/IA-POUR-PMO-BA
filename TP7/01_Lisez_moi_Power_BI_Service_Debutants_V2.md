# Pack Power BI Service débutants V2

Cette version remplace le TP technique précédent. Ne pas distribuer ses scripts DAX/Power Query/API ou comparaison A/B.

## Ordre de travail

1. Lire le nouveau cahier participant et vérifier workspace/permissions/capacité Copilot.
2. Extraire Sources/S01 : charger ces quatre CSV dans le site de test.
3. Tronc commun : importer Pilotage et Taches dans deux modèles, créer deux rapports avec les prompts, épingler six visuels vers un dashboard.
4. Extension : Risques/Jalons, deux autres modèles/rapports et tuiles.
5. Sources/S02 contient les fichiers de remplacement aux MÊMES NOMS pour mise à jour. Ne pas les prendre comme données initiales.
6. Les deux classeurs Excel S01/S02 sont des versions lisibles des mêmes données, sans formules. Le chemin d’import du cahier est CSV moderne dans Power BI Service.
7. Remplir Validation, pas de chronométrage A/B ni formules à produire.
8. Le guide formateur est réservé jusqu’à validation.

## Limites

Aucun PBIX, modèle cloud, dashboard, source publique hébergée ou achat n’est fourni/prétendument déployé. Le ZIP est une archive pédagogique, pas un package Power BI importable. Les URLs exactes du tenant sont relevées après dépôt et test. Un mode upload local reste statique tant qu’une connexion cloud n’est pas validée.

Fichiers propres/KPI précalculés : un futur changement des données réelles exige un producteur garantissant la cohérence des quatre fichiers ; pas de recalcul automatique supposé dans Power BI. Tout le cas est fictif, avec as-of16/10/2026.
